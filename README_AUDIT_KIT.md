# ערכת ביקורת קוד — 5 סוכנים (Claude Code)

ערכה מוכנה להרצת ביקורת קוד מקיפה על פרויקט WHVTAX, עם 5 סוכנים מתמחים שרצים במקביל ומייצרים דוח מאוחד ברמה של ביקורת אבטחה/קוד מסחרית.

## מה יש כאן

```
.claude/
  agents/
    security-auditor.md              ← אבטחה: AuthN/AuthZ, XSS, injection, סודות, RLS, headers
    performance-auditor.md           ← ביצועים: Core Web Vitals, bundle, שאילתות DB, קאשינג
    dead-code-auditor.md             ← קוד מת: קבצים יתומים, exports לא בשימוש, dependencies מיותרות
    error-resilience-auditor.md      ← אמינות: try/catch, race conditions, כשלי שירותים חיצוניים
    architecture-quality-auditor.md  ← ארכיטקטורה: TypeScript strictness, מבנה, כיסוי בדיקות
  commands/
    full-audit.md                    ← הפקודה שמריצה את כל 5 הסוכנים ומאחדת דוח אחד
```

כל סוכן מותאם באופן ספציפי לסטאק ולמבנה של הפרויקט הזה (Next.js 14 App Router, Supabase, Redis, אינטגרציית WhatsApp, אתר רב-לשוני עם CRM פנימי) — לא צ'קליסט גנרי.

## איך מתקינים

1. חלץ את התיקייה `.claude/` הזו **לתוך שורש הפרויקט** (`WHVTAX/`), כך שהיא תשב לצד `src/`, `package.json` וכו'. אם כבר יש לך תיקיית `.claude/` בפרויקט — מזג את התוכן (אל תדרוס קבצים קיימים בלי לבדוק).

```
WHVTAX/
├── .claude/
│   ├── agents/...
│   └── commands/...
├── src/
├── package.json
└── ...
```

2. פתח את הפרויקט ב-Claude Code (`claude` בטרמינל מתוך תיקיית הפרויקט).

## איך מריצים

בתוך Claude Code, פשוט הרץ:

```
/full-audit
```

זה יפעיל את חמשת הסוכנים **במקביל**, וכשהם יסיימו — ייצור קובץ `AUDIT_REPORT_<תאריך>.md` בשורש הפרויקט עם כל הממצאים, ממוינים לפי חומרה, פלוס תוכנית פעולה מסודרת.

אפשר גם להריץ סוכן בודד בלבד, למשל רק אבטחה:

```
בצע ביקורת אבטחה מלאה על הפרויקט לפי @security-auditor
```

## כמה זמן זה לוקח / עלות

ריצה מלאה על פרויקט בגודל הזה (~280 קבצי TS/TSX, 45 API routes) יכולה לקחת בין כמה דקות למעל שעה, תלוי בעומק. הסוכנים מוגדרים עם `model: opus` לדיוק מקסימלי — אפשר לשנות ל-`sonnet` בקובצי ה-agent אם רוצים הרצה מהירה/זולה יותר על חשבון קצת פחות עומק.

## התאמה אישית

- **להוסיף תחום שישי** (למשל נגישות/SEO/עלויות ענן): צור קובץ `.md` נוסף תחת `.claude/agents/` באותו פורמט (frontmatter עם `name`/`description`/`tools`/`model` + הנחיות מפורטות), ותוסיף אותו לרשימה בשלב 1 של `full-audit.md`.
- **להריץ רק חלק מהתחומים:** ערוך את `full-audit.md` והסר את השורות של הסוכנים שלא רלוונטים כרגע.
- **לשנות עומק:** כל קובץ agent הוא פרומפט טקסט רגיל — אפשר להוסיף/להסיר בדיקות בכל סעיף לפי הצורך.

## הערה חשובה

הריפו כבר מכיל כמה מסמכי audit קודמים (`WILL_CRM_SECURITY_AUDIT.md`, `WILL_CRM_SECURITY_AUDIT_v2.md`, `WILL_SECURITY_REVIEW.md`, `AUDIT_REPORT.md`). סוכן האבטחה מונחה במפורש לקרוא אותם ולוודא שממצאים שתועדו כ"תוקנו" באמת עדיין מתוקנים בקוד הנוכחי (regression check), במקום לדווח מחדש על בעיות ישנות בלי לבדוק בפועל.
