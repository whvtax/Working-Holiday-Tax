# audit-a11y-conv: Gates 7 and 8 (accessibility, conversion, analytics)

Method: real rendered pages on the dev server (localhost:3200), Playwright Chromium, axe-core (wcag2a/2aa/21a/21aa/22aa) on 8 page types x 6 languages at 390 and 1440, overflow/clipping/structure scan on 13 page types x 6 languages x 10 widths (320 360 375 390 414 430 768 1024 1280 1440), keyboard tests in en/de/ja/fr/es, reduced-motion emulation. All measurements are lab only (headless Chromium, dev server). The dev server restarted several times during the run, so scans were re-run with retry; final coverage listed per finding. fr/it/es have no /start or /privacy pages (they return 404 by design), so form-entry testing covers en/de/ja only.
