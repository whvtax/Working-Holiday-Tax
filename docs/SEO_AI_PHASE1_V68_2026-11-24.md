  WhatsApp bar. GA image fallback hosts added to img-src. Tests: src/lib/__tests__/whatsapp-click-23nov.test.ts.

  with the approved sign-off wording.

  generator script is not in this zip; apply the same wording there).

Jo's decisions applied (all languages, both sites)
