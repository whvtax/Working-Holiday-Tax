Site: workingholidaytax.com.au, Italian section `/it`. Prepared 5 November 2026. Read only: no site files were changed.

## How to read this

**Search Console (3 months to 5 Nov 2026).** The Italian section has almost no presence yet:
* No `/it` URL appears in the Pages export. That export has 600 rows and goes down to 1 impression, so every `/it` page had at most a handful of impressions.
* The only Italian-language query in the top 1,000 is "tasse working holiday": 19 impressions, position 28.8, 0 clicks.
* Italy as a country gave 653 impressions and 9 clicks, almost all on English pages.

So "current state" below is mostly "page exists, no GSC impressions". Where an English twin of the query has real impressions, I cite it as a sign of demand, labelled "EN twin GSC n".

**No search volumes.** These are not invented. Evidence labels:
* **SERP observed:** the phrase is used as a title, H1/H2 or FAQ on Italian-language pages that rank for it. The source domain is given. The search tool is US based, so these are Italian-language results, not an Italy-located SERP. No People also ask box was visible.
* **native phrasing:** how Italian speakers phrase it, not seen in a SERP.
* **GSC n impressions:** our own data.

All URLs start with `https://workingholidaytax.com.au`. Italian guides live at `/it/blog/<english slug>`.

## 2. Gaps

All 143 English guides already exist in Italian, so these are content gaps or missing wording, not missing translations.

1. **tax return anni precedenti / tax return dopo 2 o 3 anni.** SERP observed as a competitor FAQ. We only have FAQ lines on two service pages and a penalties guide. Add a new guide, `/it/blog/past-years-tax-returns-working-holiday`, with an English twin at `/blog/past-years-tax-returns-working-holiday`. It should cover lodging one or more old years from Italy, what the ATO needs, and refunds to an Australian account. Link it from /it/tax-return and /it/dichiarazione-redditi-australia.
2. **lavorare con ABN in Australia.** This is the wording on Italian competitor pages (SERP observed). Extend /it/abn: add an H2 using the exact phrase, and work it into the title, for example "Lavorare con ABN in Australia con il working holiday".
3. **riscattare la superannuation / contributo pensionistico partenza dall'Australia.** These are competitor and ATO wording (SERP observed). Extend /it/superannuation with one H2 or intro sentence using both phrases next to "rimborso" and "DASP".
4. **codice fiscale australiano.** This is the competitor's title phrase (SERP observed). Extend /it/tfn: put the phrase in the H1 subtitle or the opening sentence, so the first line reads "TFN, il codice fiscale australiano". Right now it is buried in a later paragraph.

**Deliberately not filled:** "dichiarare in Italia i redditi australiani / doppia tassazione Italia Australia" has clear demand (SERP observed: fiscomania.com, SBS Italiano). Site policy is not to advise on Italian tax. Keep the existing boundary FAQ that points to the Agenzia delle Entrate, and do not build a page.
